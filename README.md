# Ki-Sabdo-Langit
Ki Sabdo Langit adalah media dakwah yang berpegang pada Dalil, Ilmu, dan Hikmah: berlandaskan Al-Qur'an dan Sunnah yang sahih dengan pemahaman Salafus Shalih, dikaji secara analitis, kritis, dan beradab, serta diarahkan untuk melahirkan hikmah yang memperkuat iman, memperbaiki akhlak, dan menenangkan jiwa.
